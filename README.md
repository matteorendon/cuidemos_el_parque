# Cuidemos nuestro parque

Sitio estático responsive para el proyecto comunitario del Parque de las Patinetas, Bosa El Remanso.

## Publicar en Vercel
1. Descomprime el ZIP.
2. Sube la carpeta `cuidemos_nuestro_parque` a un repositorio GitHub, o impórtala en Vercel.
3. En Vercel, crea un proyecto nuevo e importa el repositorio.
4. Framework preset: `Other`. Build command y output directory pueden quedar vacíos; el sitio usa `index.html` en la raíz.
5. Cuando se publique, prueba el sitio desde celular y computador.
6. Genera un QR con la URL pública final. No generes el QR antes de tener la URL definitiva.

## Antes de compartir
- Verifica periódicamente teléfonos y rutas oficiales.
- Prueba cada enlace y los botones de llamada en un celular.
- Las orientaciones de salud animal son educativas; no sustituyen una valoración veterinaria.
- No publicar datos personales, imágenes ni testimonios de integrantes de la comunidad sin autorización.
